Welcome to my interactive 3D portfolio website.

While my primary expertise lies in **Backend Engineering, AI Systems, and Intelligent Automation**, this project demonstrates my ability to understand, customize, and extend a complex frontend-heavy codebase built with modern WebGL technologies.

Through reverse engineering and adaptation of an existing open-source portfolio framework, I transformed the experience into a personalized showcase of my projects, technical skills, and professional journey.

##  Running Locally

Clone the repository:

```bash
git clone https://github.com/kashish7-7/PORTFOLIO.git
cd PORTFOLIO
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
